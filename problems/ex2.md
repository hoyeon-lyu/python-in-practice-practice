# 예제 2. 센서 데이터 정리
관련 레슨: 02 리스트 컴프리헨션

한 줄에 온도(정수, ℃)들이 공백으로 주어진다. `-999`는 센서 오류 값이다. 오류가 아닌 값이 적어도 하나는 있다.
아래 5줄을 출력한다. (각 줄은 컴프리헨션 한 줄로 만들어 보자)
1. `valid:` 오류 값을 뺀 온도들 (입력 순서 그대로)
2. `kelvin:` 유효한 온도에 273을 더한 값들
3. `labels:` 유효한 온도마다 30 이상이면 `H`, 0 이하이면 `C`, 나머지는 `O`
4. `errors:` 오류 값의 개수
5. `all_above_zero:` 유효한 온도가 모두 0보다 크면 `yes`, 아니면 `no`

| 입력 | 출력 |
|---|---|
| `25 -999 31 0 -3 18` | `valid: 25 31 0 -3 18`<br>`kelvin: 298 304 273 270 291`<br>`labels: O H C C O`<br>`errors: 1`<br>`all_above_zero: no` |
| `12 5 -999 -999 7` | `valid: 12 5 7`<br>`kelvin: 285 278 280`<br>`labels: O O O`<br>`errors: 2`<br>`all_above_zero: yes` |

💡 `[식 if 조건 else 식 for ...]`처럼 if/else를 앞에, 거르는 if는 뒤에 쓴다. `print("a:", *리스트)`는 공백으로 이어 준다.
