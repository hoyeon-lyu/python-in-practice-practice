# 예제 4. 원점에서 가까운 순서
관련 레슨: 03 튜플과 언패킹

첫 줄에 점의 개수 `n`, 이어서 `n`줄에 `이름 x y`(x, y는 정수)가 주어진다.
원점까지 거리의 제곱 `d2 = x² + y²`이 작은 순서로 정렬하고, **d2가 같으면 이름의 알파벳 순서**로 정렬한다.
1. 정렬된 순서대로 `순위. 이름 (x, y) d2=값` (순위는 1부터)
2. `farthest:` 가장 먼 점의 이름 (정렬 결과의 마지막)
3. `box: (최소x, 최소y) ~ (최대x, 최대y)` 모든 점을 감싸는 상자

| 입력 | 출력 |
|---|---|
| `4`<br>`A 3 4`<br>`B -1 0`<br>`C 0 5`<br>`D 2 -2` | `1. B (-1, 0) d2=1`<br>`2. D (2, -2) d2=8`<br>`3. A (3, 4) d2=25`<br>`4. C (0, 5) d2=25`<br>`farthest: C`<br>`box: (-1, -2) ~ (3, 5)` |
| `3`<br>`q 1 1`<br>`p -1 1`<br>`r 0 0` | `1. r (0, 0) d2=0`<br>`2. p (-1, 1) d2=2`<br>`3. q (1, 1) d2=2`<br>`farthest: q`<br>`box: (-1, 0) ~ (1, 1)` |

💡 `(d2, 이름, x, y)` 튜플로 담아 `sort()`하면 앞 원소부터 차례로 비교한다. `for rank, (d2, name, x, y) in enumerate(..., start=1)`처럼 풀어서 받을 수 있다.
